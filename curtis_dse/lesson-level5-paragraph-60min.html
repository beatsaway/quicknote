1. Upgrade bank — click the weak bit

These upgrades work in almost every DSE writing task. Say the better version aloud, then click.

  1. Some people say that the plan will fail.
  2. Second of all, students need more rest.
  3. This can make parents to worry.
  4. There was a reduce in complaints.
  5. Rules can push away students for breaking them.
  6. Labels give a useful information.
  7. In a whole, I support the idea.
  8. The policy may get more worse without support.
  9. This measures are effective.
  10. We should change customers habits carefully.
Keep these upgrades Critics / Opponents argue · Secondly / Furthermore · a reduction in · discourage … from · encourage … to · In conclusion · get even worse · useful information (no a)
18–35 min

2. Build your Level 5 toolkit (any topic)

Complete each frame with your own idea. Same frames work for essays, letters, articles and proposals.

Openers / sequence

  • First and foremost, …
  • Secondly / Furthermore, …
  • Last but not least, …

Evidence / example

  • For example, …
  • This can be seen when …
  • As a result, …

Contrast / rebuttal

  • Critics may argue that …
  • However, …
  • While this concern is valid, …

Level 5 glue

  • By + -ing, …
  • …, which means that …
  • …, so …
  • This allows …

Write one full sentence for each frame. Click the writing space to check a model.

35–50 min

3. Put the toolkit into one paragraph

Choose one topic. Write 110–140 words. Use at least 5 frames from Section 2.

Pick one prompt A) Should secondary students have a later school start time?
B) Is it better to study in Hong Kong for university?
C) Should schools limit smartphone use during the day?
Must include topic sentence · For example · one result link (As a result / so / This allows — pick one, do not stack) · one precise word from today’s upgrades

Click for a transferable model paragraph (later start time)

First and foremost, a later school start time can improve students’ focus. For example, teenagers who sleep longer often concentrate better in morning lessons. By starting at nine instead of eight, schools may also reduce lateness. As a result, both marks and well-being can improve. While some critics argue that families’ schedules would be disrupted, a small change in timetable can still bring clear academic benefits.

50–60 min

4. Rebuttal kit + self-check

Write exactly 3 sentences on the same topic you chose.

  1. Critics may argue that…
  2. However, / While this concern is valid,…
  3. Therefore, / In conclusion,…

Click for a model rebuttal kit

Critics may argue that a later start time would make the school day finish too late. However, better sleep can raise learning quality, so the extra hour is worthwhile. Therefore, schools should trial a later start for senior forms first.
