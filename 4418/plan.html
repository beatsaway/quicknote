What “reportx2” means

Based on reportx2, you must submit two reports for BHMS4418: a Progress Report and a Final Report. The workflow is: proposal/draft → progress update → final report.

Progress vs Final when you are not collecting data or doing analysis

If this is a conceptual / framework-only project (no actual survey, no data analysis):

如果呢個係概念／框架為主嘅項目（唔會真係做問卷、唔會做數據分析）：

  • Progress Report focus: Show where you are now—topic chosen, main constructs and model outlined, key literature found, gaps identified, and next steps (e.g. “finalise the framework and write the full report”). The marker wants to see clear direction, credible sources, and a realistic plan. You do not need to report data or results.
  • Final Report focus: Deliver the complete conceptual product—full introduction (problem + HK context + gap), construct definitions, critical literature review, proposed framework (propositions/hypotheses), a short “method” section describing how the framework could be tested (even if you will not run the study), discussion and implications, and conclusion. The “method” part is a research plan, not a report of actual data collection or analysis.

So: Progress = evidence of progress and planning; Final = the full, polished conceptual framework that could be tested in future research.

總結：Progress 係展示進度同計劃；Final 係交出一份完整、有條理嘅概念框架，方便日後做實證研究時可以按呢個框架去驗證。

Citations: Progress vs Final

Progress Report: Use enough citations to show you have read credible sources and to support your claims (constructs, gap, model). You do not need to cite everything—around 10–15 key references are usually sufficient for 600–1,000 words. Final Report: Expand with more citations in each section (deeper literature review, more support for the framework, HK context, ethics, etc.). So yes—fewer citations in progress, more in final, is the right idea.
