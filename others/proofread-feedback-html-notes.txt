Proofread feedback HTMLs — highlighting convention
==================================================

When you build these pages (flip-to-compare yellow highlights):

• Only wrap the WORDS OR PHRASES that change in <span class="flip">…</span>.
• Leave the rest of the student’s draft as normal text (not highlighted).

Why
---
Students see their own wording most of the time. Yellow marks the exact spot to fix, like marginal notes — not a wall of highlighter over the whole paragraph.

How
---
• data-w = student’s original (wrong) wording for that bit only
• data-r = suggested replacement for that same bit
• Same click/keyboard script as in easter-holiday-recount.html and letter-to-amy-walled-city-michelle.html

Exceptions
----------
If a sentence is badly broken and every part must be rewritten together, one longer yellow span is OK so you don’t leave nonsense in plain text.

Also mention in the page copy (About / Comments) that only the yellow parts are edits; the rest is their draft as written.

Cantonese comments — always bilingual (Comments section)
--------------------------------------------------------
When helpful, add teacher tips in the **Comments** section at the end of the page (after the short English summary). When you use Cantonese (粵語), always give the same content in English in the same block.

• Put a .comment-bilingual box at the **bottom of Comments** (neutral grey outer box; see colour rules below).
• Pair EN and 粵 in .comment-pair rows: English first, then Cantonese (same meaning, same examples).
• Label lines with .lang-tag (EN / 粵) so readers can scan either language.
• Do not put Cantonese-only feedback in Comments without an English mirror.
• Copy the .comment-bilingual CSS from article-why-we-dream.html or opinion-dark-humour-memes.html when adding to a new page.

Praise + upgrades (not upgrades only)
-------------------------------------
The bilingual block should include **praise** as well as **upgrade tips**. Do not only list fixes.

• Start with **2–3 praise pairs** (what went well, in warm teacher voice). Mirror strengths from the “What went well” grid but phrase them for the student directly.
• Then add **2–3 upgrade pairs** (how to push higher). These can overlap with yellow flips and “Could be even better”.
• Example praise labels: Strong hook / Task complete / Clear stance / Empathy / Balanced view.
• Example upgrade labels: Magazine opening / Word choice / Stronger ending.
• Order: praise first, upgrades after — so the student feels encouraged before reading fixes.

Praise vs upgrade colours (students must tell them apart)
---------------------------------------------------------
Students often cannot tell which 粵 comment is praise and which is feedback. Use **two colours** inside .comment-bilingual. Colour alone is enough — do **not** add a legend or key explaining green vs amber.

• Praise pairs: class="comment-pair comment-pair-praise" (green tint #e8f5e9, left border #43a047).
• Upgrade pairs: class="comment-pair comment-pair-upgrade" (amber tint #fff8e1, left border #f9a825).
• Do **not** add Praise / 讚賞 / Upgrade / 改善 labels or badges. Colour alone tells praise from upgrade; each line only needs .lang-tag (EN / 粵).

• If a page has only upgrade-style tips (e.g. idea prompts with no praise block), use comment-pair-upgrade on every row.

• Do **not** use one purple style for all pairs — that was the old pattern and confuses readers.

Page copy style
---------------
In feedback text, demo letters, and comments, avoid en dashes (— / &mdash;) and colons after labels. Use full stops, commas, or short separate sentences instead (e.g. "Health. Play basketball…" not "Health — …" or "Health: …").
